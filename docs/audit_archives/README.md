# Legacy Audit & Forensic Archives

This directory houses legacy diagnostic reports, API schema inventories, and forensic audit documents generated during earlier development and restructuring phases of the Electric Vehicle Showroom ERP.

## Archived Documentation & Inventories

| File | Description |
| :--- | :--- |
| `ERP_FORENSIC_AUDIT.md` | Initial architectural and security forensic audit of the ERP backend services. |
| `ERP_PHASE_2_FORENSIC_AUDIT.md` | Deep-dive forensic review of Phase 2 business logic, domain boundaries, and schemas. |
| `INVENTORY_MODULE_ANALYSIS.md` | Module-specific analysis of stock levels, inventory mutations, and serial tracking. |
| `audit_report.md` | System-wide audit report detailing code health and architectural findings. |
| `frontend_audit_report.md` | Comprehensive frontend audit covering routes, components, state management, and UX. |
| `api_gap_report.json` | Machine-readable gap analysis between backend endpoints and frontend consumption. |
| `api_inventory.json` | Full inventory catalog of REST endpoints, parameters, and response structures. |

These archives are preserved for historical compliance, tracing architectural decisions, and auditing purposes. Active development documentation is maintained in the root `docs/` hierarchy.
